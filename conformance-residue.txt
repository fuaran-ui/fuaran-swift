# Conformance residue — the named set of things this surface is KNOWN not to answer.
#
# WHAT THIS IS. A committed list of the failures that stand on a clean tree against
# the current shared corpus. The gates read it and go red in BOTH directions:
#
#   * a failure NOT on this list is a REGRESSION      -> red, named;
#   * a line on this list that now PASSES is STALE    -> red, named, delete it.
#
# WHY IT EXISTS. This surface's gates were red BY DESIGN, and a run everyone
# expects to be red is a run nobody reads: a new regression lands inside an
# already-failing job with nothing to distinguish it from the standing failures.
# Naming the residue turns the expected red into a green with a stated cap, and
# gives a genuinely new failure somewhere to show up.
#
# WHAT IT IS NOT. It is not an exemption, and the distinction is the whole point.
# A DECLARED EXEMPTION (see `declaredExemptions` in RenderObligationTests.swift)
# says this surface STRUCTURALLY cannot answer a claim — it emits no attribute bag,
# no document, no network image loader — and is a permanent, reasoned answer. A
# residue entry says the surface does not model the slots the claim is about YET.
# That is unadopted work; it shrinks through adoption, never by reclassification.
# Turning a residue line into an exemption would make the gate green over a
# capability nobody has adopted, which is the one thing the mechanism prevents.
#
# HOW TO SHRINK IT. Adopt the vocabulary, register the checker or fix the decoder,
# delete the line. There is no way to make this file grow without it showing in a
# diff.
